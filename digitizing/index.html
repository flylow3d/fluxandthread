An SVG gives much better results than a photo or screenshot: the shapes and colours are exact, so nothing has to be guessed.

2  Size and colours

The finished width is the width of the design itself, not counting blank background around it.

3  Threads

Tick garment for the shirt or background colour — that one is left unstitched, so the fabric shows through. Colours are sewn top to bottom.
Stitch settings (fine tuning)
Lower density number = more thread and a solider look. Overlap stops gaps of bare fabric showing between two colours.
A drawn line is walked with a longer stitch on the straights and a shorter one round bends, so curves come out smooth without wasting thread. Extra passes sew the line back and forth over itself — this is “bean stitch”, what bought single-line embroidery fonts use to make a thin line read solidly. Each pass is offset slightly so the needle does not punch the same hole over and over.
A smooth band is what proper embroidery uses for lettering, thin shapes and thick outlines: the thread crosses the shape instead of filling it in rows, so it comes out glossy rather than flat. Only shapes that really are a simple band are done this way — anything else is filled as before. Shapes wider than the figure above are filled too, because one stitch that long would snag.
